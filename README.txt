LDCookLog Mobile V1.1 — Hosted Web App Package

FILES
- index.html
- manifest.webmanifest
- icon-180.png
- icon-512.png

PURPOSE
This version is meant to be hosted as a normal website so Safari on iPhone/iPad can run all buttons and JavaScript correctly.

RECOMMENDED HOSTING
GitHub Pages is fine for this prototype.

ONCE HOSTED
1. Open the site URL in Safari on iPhone or iPad.
2. Tap Share.
3. Choose Add to Home Screen.
4. Launch LDCookLog from the new Home Screen icon.

V1.1 LIMITATIONS
- Data is stored locally on each device.
- iPhone and iPad do not sync with each other yet.
- No direct FireBoard live connection yet.
- No direct Numbers write-back yet.

NEXT VERSION
A later version can add a shared cloud data store or Mac bridge so iPhone/iPad share the same current cook and FireBoard temperatures.
