    Independent backup

    Download a checksum-verified JSON backup, then save it to iCloud Drive using Files. Backups are manual; this prototype cannot verify that iCloud received them.

    Accepts locally exported backups or the private .relational.json made from the PostgreSQL dump. Restores are merge-only: exact duplicates are skipped, conflicting IDs cancel everything. Do not import private records to this prototype until acceptance testing is complete.
    No Supabase dependency. No FireBoard tokens. Browser storage is not a backup; verify an exported file on a second device before relying on it.
